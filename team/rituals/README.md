# الروتين (Rituals)

كل روتين هنا **مقترح فقط** — ولا يشتغل أي جدولة فعلية إلا بعد ما يوافق المالك عليها كل واحدة لحالها (حسب القاعدة الثابتة في README).

توقيت المالك: Asia/Dubai (GMT+4). آخر قرار من المالك: ما يشطّل أي روتين الحين — المقترحات جاهزة للتفعيل وقت ما يحب.

## 1. ملخص الصباح — كل يوم 8:00 ص (بتوقيت المالك)

يسوّيه: المدير التنفيذي.

- يقرأ اللوحة: المهام الشغالة، كروت «ينتظرك»، وختام أمس.
- يكتب ملخص اليوم في days/[تاريخ اليوم]:
  1. وش لازم يسويه المالك اليوم (3 أشياء بالكثير).
  2. خطة كل قسم بسطر واحد.
  3. خطة بديلة ليوم صعب (لو تراكمت كروت «ينتظرك» أو في تصعيد).
- ممنوع فيه: النشر، الإرسال، الدفع، أو تغيير أي إعداد.

## 2. ختام اليوم — كل يوم (وقت يحدده المالك، مقترح 6:00 م)

يسوّيه: المدير التنفيذي، بتجميع تقارير الأقسام.

- يجمع تقارير الأربع أقسام (تم / الملفات / يحتاج المالك / متوقف / التالي).
- يحدّث recent على اللوحة.
- يطلع قائمة «يحتاج المالك» النهائية لليوم — مرة واحدة مجمّعة، مو رسالة لكل حالة.

## 3. اجتماع الأسبوع — مرة أسبوعيًا (يوم ووقت يحددهم المالك)

يسوّيه: المدير التنفيذي + ملخص من كل قسم.

- تقرير الناشر الأسبوعي (الأداء).
- أي قاعدة جديدة انضافت في README خلال الأسبوع (من تصحيحات المالك).
- مقترحات ترقية مستوى (XP) لأي قسم وصل حد مستوى جديد — يُعرض على المالك، ما يُفعّل تلقائي.

## 4. المراجعة الشهرية — مرة شهريًا

يسوّيه: المدير التنفيذي.

- مراجعة شاملة: هل خط الشغل (الباحث ← الكاتب ← المونتير ← موافقة المالك ← نشر) لسه مناسب؟
- هل في قسم محتاج تعديل بالـ JD أو الـ checklist؟
- ملخص XP ومستويات كل قسم للشهر.

## 5. فحص الليل — يومي أو حسب الحاجة (مقترح، وقت يحدده المالك)

يسوّيه: المدير التنفيذي.

- فحص سريع: فيه كروت «ينتظرك» قديمة ما اتحلت من أكثر من يوم؟
- فيه حالة «متوقف» بدون سبب واضح؟
- لا قرارات، بس رصد وتنبيه في تقرير الصبح الجاي.
