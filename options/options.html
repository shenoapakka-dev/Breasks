Breaks – ETM Trip Planner Settings

Pan Home delivery trip planning. Changes are saved locally in this browser and used the next time you run a plan on the ETM page.

Warehouse

Default: 122 (Al Sajaa, Sharjah – Pan Home DC). Stops are ordered farthest → nearest relative to this point.

Vehicle capacity

Used as the volume ceiling per trip when bin-packing orders. If your fleet has mixed sizes, set the smallest common size here and adjust per trip manually after building the plan.

Travel speed assumption

Used only to convert the distance table's km into estimated travel minutes between stops, for the time-budget check.

Daily slots

Subtracted from each slot's window to leave margin for loading, breaks, and traffic.

Exclusion rules

An order is excluded from planning if its number starts with one of the excluded prefixes, OR it matches either Sales Return rule above.

Area mapping overrides

When the ETM "Area" column value doesn't match a known area code, you map it once from the planner panel. Saved mappings appear here and can be removed.
